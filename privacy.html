Privacy Policy: Arch Linux Backup

Last updated: 21 October 2026

Who uses this app

Arch Linux Backup is a personal tool used only by its owner to back up their own computer to their own Google Drive. It is not offered to the public.

What data it accesses

The app uses rclone and Google's OAuth sign-in to read and write files in the owner's Google Drive. It only handles the files the owner chooses to back up.

How the data is used

Files are uploaded to, and restored from, the owner's own Google Drive. That is the only use.

What is not collected or shared

  • No data is sent to the developer or to any server other than Google Drive.
  • No data is sold, shared with third parties, or used for advertising.
  • No analytics or tracking is used.

Storage and deletion

Backups are stored in the owner's Google Drive and can be deleted there at any time. The sign-in token is stored only on the owner's computer and can be revoked at any time from Google Account > Third-party connections.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
